体渲染的可信度：从体素采样到像素合成.

一张漂亮的体渲染图并不是原始数据本身。理解几何映射、插值、传递函数和射线积分，才能知道画面表达了什么，也知道它可能在哪里失真。

本文目录一张图经过哪些环节射线积分采样步长与透明度插值和传递函数梯度、法线与光照失效模式验证记录结语公开参考资料

体渲染最容易被评价的是画面：有没有层次、阴影够不够柔和、血管是否清楚。但工程上更值得追问的是：这张二维图像究竟由哪些数据和参数生成？改变采样步长、传递函数或相机后，哪些变化是预期的，哪些变化说明表示已经不稳定？

直接体绘制（Direct Volume Rendering, DVR）不是把体素简单“画出来”，而是沿视线对连续场进行采样、分类和积分。最终像素是整条射线上许多样本共同作用的结果。因此，体渲染图像适合帮助理解空间关系，却不能自动替代原始切片、定量测量或任务级验证。

一张图经过了哪些环节

一条典型的 DVR 管线可以拆成六步：

  1. 数据与几何：读取体素值，同时保留原点、方向矩阵、spacing、层厚和强度单位。数组下标不是物理坐标。
  2. 空间变换：把世界坐标中的射线采样位置变换到体数据坐标系，处理非等距采样和斜切方向。
  3. 重采样：在射线位置附近读取离散体素，常见方法是三线性插值；边界外如何处理也会影响结果。
  4. 分类：通过传递函数把强度及梯度等属性映射为颜色和光学属性，通常包括不透明度或消光系数。
  5. 积分与光照：沿视线累积颜色、透射率和光照贡献；不同渲染器可能采用不同的近似。
  6. 显示变换：进行色调映射、窗口显示、颜色空间转换和最终屏幕合成。

几何变换尤其容易被低估。若体数据的索引坐标为 i，物理坐标通常应由一个包含方向、间距和原点的仿射变换得到，而不只是分别乘三个 spacing。对于方向矩阵为 D、间距矩阵为 S、原点为 o 的数据，可写成：

x_world = o + D · S · x_index
x_index = (D · S)⁻¹ · (x_world - o)

如果把数组轴顺序、病人坐标方向或体素中心/边界约定弄错，画面可能仍然“看起来合理”，但空间定位已经不可靠。

射线积分：像素不是某一个体素

在 emission–absorption 模型中，沿射线位置 r(t) 的标量值经分类后得到颜色 c 和消光系数 σ。透射率表示光线走到当前位置时还剩多少未被吸收的能量：

T(t) = exp(-∫₀ᵗ σ(f(r(s))) ds)

C(r) = ∫₀ᴰ T(t) · σ(f(r(t))) · c(f(r(t))) dt
       + T(D) · C_background

实际 GPU ray marching 会把连续积分离散成一系列采样段。对第 i 段，若局部消光系数近似为常数，段不透明度可以写成：

αᵢ = 1 - exp(-σᵢ · Δs)

Cᵢ₊₁ = Cᵢ + Tᵢ · αᵢ · cᵢ
Tᵢ₊₁ = Tᵢ · (1 - αᵢ)

这里的 Δs 是沿射线的物理采样距离，不应与体素数组下标步长混为一谈。当前样本的颜色贡献会被前面样本留下的透射率 Tᵢ 调制，这也是前向 alpha compositing 的核心。

采样步长改变时，不透明度也要跟着变

一个常见陷阱是：只把 ray step 调大或调小，却仍使用同一份每步 alpha。这样每单位物理长度的累计吸收量就变了，最终图像自然会变亮、变暗或显得更厚。若某个参考步长 Δs₀ 下的 alpha 为 α₀，在同一均匀介质假设下，步长改为 Δs 时可按下式修正：

α(Δs) = 1 - (1 - α₀)^(Δs / Δs₀)

这不是所有渲染实现都能直接套用的万能补丁：若分类、插值或光照在一个采样段内变化很大，常数消光近似本身就不成立。但它说明了一个原则：性能参数不能脱离物理步长和光学模型单独调节。

插值和传递函数通常不交换

假设一个采样位置落在八个体素之间，三线性插值先对标量值加权求和。若传递函数是非线性的，通常有：

TF(Σ wᵢ · fᵢ) ≠ Σ wᵢ · TF(fᵢ)

左边是先插值标量、再查传递函数；右边是先对每个体素分类、再插值颜色与透明度。两种路径的视觉结果可能不同，尤其当 TF 有窄峰、陡峭边缘或多个相邻组织区间时。

预积分（pre-integrated classification）就是为了解决高频 TF 与较粗采样之间的一部分误差：它不只看采样点的 TF 值，而是根据线段两端的标量值，预先近似积分该段内部的颜色和不透明度贡献。典型实现把端点标量对映射到二维查找表。它能减少尖锐 TF 下的条带和漏采，但并不意味着可以任意降低采样率；表分辨率、标量变化假设、插值方式和梯度计算仍然重要。

多维传递函数进一步把梯度大小、材料类别或其他属性纳入分类空间。它能帮助分离强度区间重叠的边界，也增加了设计和验证的复杂度：同一 HU 值在不同梯度或组织标签下，可能被映射成完全不同的颜色与透明度。

梯度、法线与光照：增强形态，不等于增加数据

很多高质量体渲染会用标量场梯度估计局部法线，再计算漫反射、高光、阴影或环境光遮蔽。若体数据的索引坐标与物理坐标之间存在非单位 spacing 或方向旋转，梯度也必须正确变换。对线性变换矩阵 A，梯度满足：

∇world f = A⁻ᵀ · ∇index f

直接在数组坐标里算差分、再把结果当成世界空间法线，可能造成方向和尺度错误。尤其在厚层数据、各向异性体素和斜切采样中，spacing-aware gradient 是必要条件。

还要区分两个概念：梯度和光照可以让边界更容易被看见，但它们不会创造新的原始测量信息。阴影、材质、去噪、锐化或色调映射都可能增强视觉线索，也可能改变局部对比。图像更有层次，不等于结构位置更准确。

最值得检查的四类失效

失效类型典型表现优先核查
几何错位斜切面、左右方向、尺度或层间距异常原点、方向矩阵、spacing、轴顺序和坐标约定
采样不足薄结构断裂、细节随视角闪烁、边缘呈阶梯物理步长、屏幕像素 footprint、插值和预积分设置
分类偏差组织忽隐忽现，改变 TF 后边界大幅移动TF 曲线、梯度维度、强度范围和透明度校正
光照误导阴影看起来像边界，去噪后小结构消失关闭光照/后处理，对照原始切片与 MPR

对于细血管、薄骨皮质、低对比边界等目标，建议把视图拆成三个层次：全局视图检查空间关系，局部 ROI 检查细节，原始切片或 MPR 检查数据依据。只看一张全局截图，往往会把局部失真平均掉。

一份更有用的验证记录

验证不是“选一张好看的图”，而是固定变量后主动寻找失败条件。下面这份记录表适合用于比较两个渲染实现或一组参数：

层级固定条件观察/指标不能单独证明什么
数据层同一体数据、几何元信息、预处理版本体素值抽样、spacing、方向和 ROI 坐标一致不能证明渲染图像视觉质量
积分层同一 TF、采样步长、插值和背景参考积分误差、透明度累计、亮度范围不能证明结构任务准确
结构层同一相机、同一裁剪面、同一局部 ROI边界偏移、连通性、薄结构保留、局部差异不能代替临床任务验证
稳定性层只改变一个变量步长减半、视口缩放、TF 微调后的变化趋势不能证明所有设备和数据都一致
  1. 先固定数据和几何：同一份源数据、同一 spacing、同一方向矩阵和预处理版本。
  2. 再固定渲染参数：相机、TF、采样步长、插值、梯度、光照、背景和输出色彩空间。
  3. 定义 ROI 后再跑对照：至少包含高对比边界、细小结构、低对比区域和容易产生伪影的位置。
  4. 逐个改变变量：例如先只改采样步长，再只改 TF，避免同时修改多个参数后无法归因。
  5. 保存结果与失败样本：包括参数、版本、差异图和未通过的 ROI，而不是只留最佳截图。
一个可靠的渲染结论应该能够回答：在哪些数据、视角、TF 和采样条件下成立？换一个条件后，哪里开始失效？

结语：把渲染当作一条可解释的计算链

体渲染的质量由数据几何、重采样、分类、积分、梯度和显示共同决定。优化其中某一步，可能改善性能或观感，也可能把误差转移到别处。真正有价值的工程记录，应该让别人知道输入是什么、参数是什么、结果如何复现，以及哪些问题还没有被证明。

这里讨论的是图形学和可视化层面的工程验证，不构成临床诊断建议，也不意味着体渲染图像可以替代原始医学影像或经验证的测量流程。
