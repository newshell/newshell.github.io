诊断级体渲染：从视觉效果到可信证据.

画面足够漂亮，并不意味着对组织结构的解释足够可靠。真正重要的是输入数据、可复现参数和失效边界。

一张有体积感的 CT 渲染图，可能在评审时让人很快点头。但如果薄血管一换采样步长就消失、不同显示器上的边界厚度不一致，漂亮就没有帮我们回答工程问题。这篇不展示未公开的产品效果，也不声称完成了临床试验；这里只用公开的成像标准和体绘制原理，把一组可以实际做的检查写下来。

先把输出定义清楚：DVR 是数据解释与观察的工具；几何测量、定量判断及诊断结论，应使用具有相应验证依据的流程。不能把“能回到原始数据”直接等同于“具备诊断资格”。

第一处容易混淆的量：存储值、HU 与坐标

对常规 CT 图像，不应默认纹理里的整数就是 HU。DICOM 定义了像素存储值经 Rescale Slope 与 Rescale Intercept 转换的关系：output = slope × stored + intercept。但要结合图像类型、Rescale Type 等字段确认输出单位，不能对所有模态无条件套用 HU。

体素还有另一层常被忽略的语义：索引坐标不是世界坐标。DICOM 的 Pixel Spacing、Image Orientation (Patient)、Image Position (Patient) 描述了行列方向与物理位置；Slice Thickness 是标称厚度，不等价于相邻切片中心距。把这几个字段都粗暴地当作三维 spacing，斜位重建的空间关系就可能不对。

输入应该记录的内容典型检查
像素强度Stored Value、Slope/Intercept、单位抽取若干固定坐标核对转换结果
空间变换Origin、行列方向、切片位置、Spacing对照 MPR 中的同一物理点
预处理重采样、降噪、裁剪与版本确保对照双方使用同一数据链路

这一步不炫技，却能避免后续所有渲染差异被错误归因给 Shader。

光线积分不是“每隔几步取一次颜色”

最常见的直接体绘制实现沿视线累积样本。采用发射—吸收近似时，可以把第 i 段的颜色与不透明度记为 cᵢ, αᵢ，前向合成写成：

C ← C + (1 − A) · αᵢ · cᵢ
A ← A + (1 − A) · αᵢ
if A is sufficiently close to 1: stop

这只是一段说明公式的伪代码；其中的 cᵢ 究竟是否预乘 alpha，必须与完整实现的约定一致。若传递函数中存的是“参考距离 d₀ 的不透明度 α₀”，变更采样步长 d 时，常用的一种修正是 α(d) = 1 − (1 − α₀)^(d/d₀)。它来自吸收率按距离累积的假设，不能拿来修补任意没有距离语义的透明度参数。

一个有针对性的回归用例是：固定相机、TF、窗口与同一体数据，只改变步长；比较主要组织的累计不透明度分布、边界位置与细结构可见性。图像像素严格相同通常并不是合理预期，重点是差异是否收敛、是否有局部结构突变。

传递函数为什么会与步长耦合

采样点之间不仅有空间距离，还有数值变化。某个很窄的高不透明度区间如果恰好落在两个样本中间，两个端点的查表结果可能都接近透明，结果却漏掉整段对图像的贡献。对高频、非线性的 TF，这是典型的采样问题。

预积分（pre-integration）的核心不是提高纹理分辨率，而是在给定相邻样本强度和段长度的条件下，近似积累这段区间内的光学贡献。它能够缓解某些采样伪影，但也增加了 TF 更新、梯度阴影和数据分布假设的设计复杂度；预积分并不能从欠采样的原始体数据里恢复真实不存在的信息。

应该分别测三组 TF：缓变单峰、窄峰和多峰重叠。每组固定相机进行多级采样，再看不透明度直方图、ROI 边界和预积分开关差异，而不是只挑一组最鲜艳的结果展示。

法线、照明和“看起来更锐利”的陷阱

DVR 中的明暗通常由体强度梯度构造局部方向，再结合光照模型得到。梯度不是表面几何的完美法线：滤波半径、差分核、各向异性 spacing 和边界采样都会改变它。尤其在细骨皮质或噪声较强的区域，提高高光对比度可能让局部线条更显眼，也可能让伪影更像真实边界。

一个实用的对照顺序是：关闭照明只看 TF/合成结果 → 固定梯度算法比较光照 → 最后单独加上后处理。不要同时调整锐化、梯度与传递函数，否则很难知道到底是谁改变了图像。

这里刻意不列任何“提升了多少 FPS / 误差下降多少”的数字，因为没有公开可复现的基准测试，就不应该把建议写成已验证性能。

最小可复现的验收矩阵

与其把截图拼成一张评审 PPT，不如从一开始就定义输入、参数和失败判据。下面是一份可供独立原型使用的清单：

维度变化项应观察的现象
强度Slope/Intercept、TF 窄峰强度解释是否正确、薄组织是否漏检
空间各向异性、倾斜切片与原始切片 / MPR 的物理位置是否一致
采样步长、插值、预积分ROI 差异是否随精度提高而收敛
外观梯度核、阴影、去噪可见性改善是否伴随结构偏移
交互裁剪、旋转、缩放不同视角是否暴露结构断裂和裁剪伪影
  1. 使用许可公开或自行生成的合成数据；给合成几何定义已知的球、细管和薄层真值。
  2. 保存参数 manifest：数据 hash、相机、TF、步长、插值、梯度、光照、后处理。
  3. 先统计全图分布，再检查结构区域和局部 ROI；只看全图平均误差会让少量高价值像素被淹没。
  4. 人为引入一个故障，例如误用 spacing 或移除透明度距离修正，确认测试确实能抓到退化。
  5. 所有结论分别标注“公开资料支持”“合成实验观察”“尚待真实数据验证”。

如果没有 ROI 级的对照，最多只能说“视觉上更顺眼”；如果没有合格的任务级验证，就不能说“诊断更可靠”。
